## 📝 Project Overview

This website is crafted for digital marketing agencies to present their services, expertise, and client feedback in a stylish and structured way. Built with responsive web design practices using Bootstrap 5.

---

## 💡 Key Sections & Features

### 🧭 Top Navigation
- Sticky header with menu: Home, About Us, Services, Portfolio, Reviews, Contact Us

### 🎯 Hero Section
- Headline and CTA button
- Background image with professional business theme

### 🧑‍💼 About Section
- Company story section with profile image and "View Portfolio" CTA

### 📈 Services Section
- Grid layout showing six service cards:
  - Drive More Sales
  - Discussion for Idea
  - Handled by Expert
- Each card includes an icon, short description, and "Read More" link

### 🗂️ Portfolio Section
- Showcases completed marketing projects (image + title layout)

### 📢 Call-to-Action Banner
- Encourages clients to start their web project with a strong CTA

### 🌟 Testimonials
- Client reviews in a 3-column layout, featuring avatars and role

### 📬 Contact Section
- Contact form with fields for name, email, subject, and message
- Contact details: phone, email, and office address
